# GaTech - Deep Learning Course

This is the CS 7643 Deep Learning course from the Georgia Tech. Please see the course contents https://sites.cc.gatech.edu/classes/AY2023/cs7643_spring/. 

It provides an introduction of neural network foundations, including:

- Deep neural network framework (DNN)
- Convolutional neural networks (CNN)
- Recurrent neural networks (RNN)
- Long short-term memory (LSTM)
- Transformers 
- Reinforcement learning (RL)

Pretty awesome course to start with in deep learning and go deeper from here.
